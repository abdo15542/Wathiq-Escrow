# Wathiq Escrow — واثق

منصة قيد التطوير لتداول USDT مقابل الدينار الليبي باستخدام ضمان على البلوكشين.

**الحالة الحالية: نموذج أولي، وليس خدمة مالية جاهزة للإنتاج. لا تستخدم أموالًا حقيقية.**

## المكونات الحالية

- `contracts/WathiqUSDTP2PEscrow.sol`: عقد أولي لضمان USDT.
- `contracts/MockUSDT.sol`: رمز اختباري فقط، وليس USDT حقيقيًا.
- `contracts/WathiqEscrow.sol`: عقد أقدم لضمان BNB، منفصل عن مسار USDT الحالي.
- `test/`: اختبارات Hardhat للعقود.
- `api/`: واجهة API أولية. بيانات العروض مخزنة في الذاكرة وتُفقد عند إعادة تشغيل الخادم.
- `web/`: واجهة ويب أولية؛ ربط المحفظة لا يعني أن العقد متصل بها، وصفحة الإدارة ليست لوحة إدارية آمنة.
- `mobile/`: تطبيق Flutter أولي؛ ليس هدف الإصدار الحالي، ولا يُفترض أنه متصل بعقد منشور.
- `.github/workflows/ci.yml`: فحوص آلية للعقود وAPI وبناء الويب وAndroid.

## مسار الصفقة المستهدف

1. ينشئ البائع صفقة ويودع USDT في عقد الضمان.
2. يدفع المشتري الدينار الليبي للبائع خارج البلوكشين.
3. يبلّغ المشتري عن الدفع.
4. يؤكد البائع استلام الدينار؛ عندها يحرر العقد USDT للمشتري.
5. إذا وقع خلاف، تُجمّد الصفقة ويُحال النزاع إلى المشرف المعيّن في العقد.

إبلاغ المشتري عن الدفع ليس إثباتًا مصرفيًا. التأكيد اليدوي والنزاعات يحتاجان إلى إجراءات تشغيل واضحة، وجمع أدلة، وصلاحيات موثوقة، ومراجعة قانونية.

## الشبكات

لم يُحسم اختيار شبكة USDT للإنتاج. يجب مقارنة الشبكات من حيث دعم المحافظ، والسيولة، والرسوم، وتوفر USDT الرسمي، وتجربة المستخدم في ليبيا قبل القرار.

إعدادات BNB Smart Chain Testnet الحالية تستخدم chain ID 97. رمز MockUSDT المنشور للاختبار لا يجوز اعتباره USDT حقيقيًا.

## التطوير والاختبارات

المتطلبات: Node.js 20+ وnpm.

```bash
npm install
npm --prefix api install
npm run compile
npm test
npm run test:api
npm run build:web
```

لا تُعد أي مجموعة اختبارات ناجحة إلا بعد تشغيلها ومراجعة نتيجتها الفعلية. نجاح الاختبارات لا يثبت وحده أمان العقد أو جاهزية الخدمة المالية.

## ما ينقص قبل إطلاق حقيقي

- توحيد واجهة الويب وAPI حول عروض USDT وسعر الدينار الليبي.
- ربط المحفظة بالعقد الصحيح والتحقق من الشبكة وعنوان الرمز.
- قاعدة بيانات دائمة، ومصادقة، وصلاحيات، وسجل تدقيق.
- عرض الصفقات من أحداث البلوكشين مع التحقق من الحالة الفعلية.
- سير عمل للنزاعات والأدلة وقرارات المشرف.
- اختبارات تكامل على شبكة اختبار وتدقيق أمني مستقل.
- مراجعة قانونية وتنظيمية، ومراقبة، ونسخ احتياطية، وخطة استجابة للحوادث.

لا تُنشر عقود بأموال حقيقية قبل إكمال هذه المتطلبات.
